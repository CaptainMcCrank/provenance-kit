# Product Proposal — Provenance Fixture

A deliberately tiny proposal used only to exercise the provenance pipeline
end-to-end in tests. It is not a real product.

## Goal

Stand up a one-page web app that displays the current time. One agent per
pipeline stage runs against this proposal so the parity test has a realistic
(if minimal) session to inspect.

## Constraints

- Single static page, no backend.
- No external network calls at runtime.
